# PageRank

My Python implementation of PageRank.

## How do I run this?

First, download the Python code [here](https://github.com/churroTheDuck/Intro-to-Algorithms/raw/refs/heads/main/pagerank.py.).
Then, open your terminal and check if you have Python installed by running the following command:
```bash
python3 --version
```
A version number should appear. If you get an error, install Python [here](https://www.python.org/downloads/).
After making sure you have downloaded Python, use the cd commannd to navigate to the folder where the .py file is stored.
Now, run the file by typing python3 followed by the file name.
